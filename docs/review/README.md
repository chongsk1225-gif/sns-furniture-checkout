# Review screenshots

`before/` is the original storefront (the unmodified Worker serving `public/`). `after/` is the redesign preview.
Each file is named `<page>-<desktop|mobile>.jpg`. Desktop is 1440 px wide; mobile is a 390 px viewport at 1.5x.

Pages with no counterpart in `before/` (Custom Furniture, Custom Living, Design Services, Room Inspiration, Collections, a collection page) did not exist on the original site.
The home page captures were taken after the opening sequence finished.

`hero-motion/` holds frame strips of the opening sequence (300 ms to 8.5 s) at desktop and mobile size. `compare-desktop.jpg` and `compare-mobile.jpg` put before (left) and after (right) side by side for Home, Stock, Living/Product and Cart.
The opening shows the owner photograph with no filter, transform or blend applied; the measured difference from the original file is rescaling only.
